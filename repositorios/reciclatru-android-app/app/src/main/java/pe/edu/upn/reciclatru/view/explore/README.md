# view/explore

**Dominio:** exploración — pedidos disponibles (HU del reciclador).

Explorar pedidos disponibles. La lista solo muestra lo que el DTO de ese rol permite ver.

- `view/explore/` — `AvailableOrdersScreen` y `AvailableOrderFormat`.
- `viewmodel/explore/` — `AvailableOrdersViewModel` y `AvailableOrdersUiState`.
- `domain/usecase/explore/`, `domain/repository/explore/` (incluye `DeviceLocationProvider` y `LocationPromptStore`) y `model/explore/`.
- `data/local/explore/` — ubicación del dispositivo y preferencia del aviso de ubicación.
