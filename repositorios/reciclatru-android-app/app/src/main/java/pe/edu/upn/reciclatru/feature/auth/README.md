# feature/auth

**Dominio:** autenticación — registro e inicio de sesión (HU de acceso).

Registro e inicio de sesión de vecinos y recicladores. El rol elegido en el registro viaja en las peticiones, pero quien autoriza es la API.

- `ui/` — pantallas, ViewModel y navegación de la feature.
- `domain/` — modelos, casos de uso y contrato de repositorio.
- `data/` — API, DTOs, mappers e implementación del repositorio.
