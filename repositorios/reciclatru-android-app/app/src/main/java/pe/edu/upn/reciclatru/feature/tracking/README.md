# feature/tracking

**Dominio:** seguimiento — estado, contacto y evidencia (HU de seguimiento y cierre).

Seguimiento de un pedido aceptado: estado, datos de contacto cuando corresponden y fotos de evidencia. La API decide qué se expone en cada estado.

- `ui/` — pantallas, ViewModel y navegación de la feature.
- `domain/` — modelos, casos de uso y contrato de repositorio.
- `data/` — API, DTOs, mappers e implementación del repositorio.
