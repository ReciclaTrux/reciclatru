# feature/orders

**Dominio:** pedidos — publicación, materiales y cancelación (HU de publicación y gestión).

Pedidos del vecino: publicar un pedido con materiales y pesos, ver los propios y cancelarlo. El estado y las transiciones válidas los define la API.

- `ui/` — pantallas, ViewModel y navegación de la feature.
- `domain/` — modelos, casos de uso y contrato de repositorio.
- `data/` — API, DTOs, mappers e implementación del repositorio.
