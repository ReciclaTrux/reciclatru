# features/explore

**Dominio:** exploración — pedidos disponibles y aceptación (HU del reciclador).

Explorar pedidos disponibles y aceptarlos (reciclador). La lista y el detalle solo muestran lo que el DTO de ese rol permite ver.

- `presentation/` — pantallas, controller/provider y navegación de la feature.
- `domain/` — entidades, casos de uso y contrato de repositorio.
- `data/` — API, DTOs, mappers e implementación del repositorio.
